Рабочая папка - это папка на компьютере, в которой редактируются файлы
Индекс - это область, куда файлы попадают после git add перед сохранением
Коммит - это сохранение изменений с определённым сообщениями

Git - это программа на компьютере, которая сохраняет версии
GitHub - это это сайт в интернете, куда выкладываются эти версии
git diff показывается разницу между рабочей папкой и индексом
git diff --staged показывает разницу между индексом и последним коммитом
