git log --oneline --stat - показывает историю коммитов в сокращённом виде(1 строка) и статистику изменений: какие файлы были изменены и на сколько строк
git diff HEAD~2 HEAD - показывает разницу между текущей версией файла и версией двухкоммитной давности. Она показала, какие строки кода я изменила за это время
git show - показывает подробности конкретного коммита: кто его сделал, когда, какое было сообщение и какие строки в файлах изменились
git log -S'def' - ищет коммиты, в которых появлялась или исчезала указанная строка (в данном случае 'def'). В моем файле нет функций, поэтому команда ничего не нашла, но она нужна для поиска конкретных изменений в коде
git blame - показывает, кто и в каком коммите добавил каждую строчку в файле

git restore отличается от git restore --source тем, что первая возвращает к последнему коммиту, вторая — к указанному коммиту, например, HEAD~2
Если бы я просто закоммитила правки, то они бы просто перезаписались, если бы я не сохранила их в отдельный коммит
