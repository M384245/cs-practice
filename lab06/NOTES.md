# Лабораторная 6

## Реализация функций
- count_by_extension считает файлы по расширению. Расширение приводится к нижнему регистру. Файлы без расширения игнорируются.
- deepest_path находит путь с максимальным количеством разделителей /. При равенстве выводит первый по алфавиту.
- human_size переводит байты в KB, MB, GB (деление на 1024) с одним знаком после запятой. Байты выводятся без дробной части.
