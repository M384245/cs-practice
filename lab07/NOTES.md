# Лабораторная 7

## Реализация
- csv_to_records использует csv.reader и io.StringIO для парсинга текста. Первая строка используется как заголовки.
- parse_settings разбирает YAML-подобные строки. Использует split(':', 1) для разделения ключа и значения. Приводит типы: true/false, null, int, float. Комментарии и пустые строки игнорируются.
- merge_by_key объединяет два списка словарей. Если ключ совпадает, данные из правого списка обновляют левый. Если нет — добавляются в конец.
- records_to_json использует json.dumps с параметром ensure_ascii=False, чтобы русские символы выводились как есть, а не в виде unicode-последовательностей.
