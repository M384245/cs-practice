# Лабораторная 5

## Построчное чтение
Чтение реализовано через with open(filename, encoding="utf-8") as f: и цикл for line in f:. Это позволяет не загружать весь файл в память (он может быть огромным), а читать по одной строке.

## Кодировка
encoding="utf-8" указана всегда, чтобы русские сообщения в логах читались корректно на любой системе.
